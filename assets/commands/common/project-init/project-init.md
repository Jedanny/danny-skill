# Project Init Command

## Description
交互式项目初始化工具，根据选择的项目类型和配置生成项目脚手架。

## Supported Templates

### 1. Node.js
- Express/Koa/Egg.js
- TypeScript 默认支持

### 2. React
- Vite + React + TypeScript
- TailwindCSS 可选

### 3. Vue
- Vite + Vue + TypeScript

### 4. Next.js
- App Router
- TypeScript 默认

## Usage
```bash
npx @danny-skill/project-init
```

## Interactive Options
1. Project name
2. Template selection
3. Additional features (ESLint, Prettier, etc.)
4. Git initialization
